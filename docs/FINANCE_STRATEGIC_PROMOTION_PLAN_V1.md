# FINANCE_STRATEGIC_PROMOTION_PLAN_V1

## 목적
`AI_invest`를 마이크로 반응형 실험기에서, 시장 우호 구간에만 진입하고 플랜 기준으로 보유/청산하는 전략형 운용 구조로 승격한다.

## 현재 문제
- 미세 신호 반응형 성격이 강하다.
- 진입 이후 보유 철학보다 실시간 gate/stop 반응이 더 강하다.
- 사용자 기대는 "지수가 좋으면 사고, 플랜대로 들고 가다가 팔 때 되면 파는 구조"에 더 가깝다.

## 승격 방향
1. **plan-led execution 강화**
   - inter-slot/realtime 진입을 축소하고 governance/trade_plan 주도 비중을 높인다.
2. **상위 시장 우호도 필터 강화**
   - regime / market trend / alpha 지속성이 충분히 좋을 때만 BUY 허용.
3. **보유 철학 강화**
   - 진입 후 바로 흔들려도 털리지 않도록 min-hold, continuity, time-stop 구조를 전략형으로 조정.
4. **청산을 plan-reactive로 이동**
   - 짧은 미세 반응보다 plan expiry / invalidation / partial-take-profit / trailing 중심.
5. **거래 수 감소, 플랜당 품질 상승**
   - 하루 소수 거래만 허용.

## 이번 1차 반영 원칙
- 실시간 즉흥 진입을 줄인다.
- 계획 보유 시간을 늘린다.
- 시장/알파가 약하면 진입하지 않는다.
- 이미 있는 stop 체계는 유지하되, 전략형 보유/청산 철학이 우선되도록 조정한다.

## 기대 효과
- 불필요한 미세 왕복 감소
- BUY 빈도 감소, 품질 상승
- 포지션 운용이 거래 반응형이 아닌 계획형에 가까워짐
- 사용자 체감상 "전략적으로 운영한다"는 느낌 회복

## 리스크
- 거래 기회 감소
- 초기에는 지나치게 조용해질 수 있음
- 일부 좋은 실시간 기회도 놓칠 수 있음

## 운영 원칙
- 성격상 이는 실거래 리스크/전략 수정이다.
- 변경 후 반드시 오케스트레이터 정상 구동과 최근 SAFE_DECISION 흐름을 확인한다.
- 이후 1~2 거래일 관찰 후 추가 미세조정을 검토한다.
